---------------------------------------------------------------------------------------
TROUBLESHOOTING
---------------------------------------------------------------------------------------
- NoBrokersAvailable: Kafka is still starting. Wait about 20 s (docker ps should show "healthy").
- Port 9092 or 8137 already in use: stop the other Kafka/uvicorn process, or docker compose down.
- Clean restart: docker compose down  then  docker compose up -d --build
  (topics and the worker's in-memory dictionary are reset)
- Worker code changed: docker compose up -d --build worker
