----------------------------------------------------------------------
1. Install Dependencies
----------------------------------------------------------------------
Requirements:
- Python 3.10+  
- pip  
- Ollama installed locally with model qwen3:4b (or qwen3:8b)
- The following Python packages:

Run:
pip install fastapi uvicorn pydantic langchain langchain-community requests

(If langgraph is not installed:)
pip install langgraph

----------------------------------------------------------------------
2. Start FastAPI Backend (PORT_BASE = 8137)
----------------------------------------------------------------------
From the repository root directory:

uvicorn code.web_application.hw2_main:app --port 8137

Verify backend is working:
Open browser → http://localhost:8137/restaurants

----------------------------------------------------------------------
3. Test LangGraph Manually
----------------------------------------------------------------------
From repository root:

python -c "from code.hw2_graph import run_graph; print(run_graph('Test','Content',max_turns=5))"

Expected:
A dictionary with planner_output, reviewer_output, success=True or False.

python code/compare_ceiling.py

reports/hw02/raw/ceiling_compare.json
