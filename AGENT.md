# Project Instructions

- Project description: extend the DATA260 restaurant-inspection application for HW6.
- Technology stack: keep FastAPI for HTTP routes, MySQL for the existing relational domain, and local MongoDB for document memory.
- Technology stack: use the local Ollama adapter and do not require a paid hosted model.
- Coding convention: use type hints, Pydantic validation, clear HTTP status codes, and small service functions.
- Testing approach: every new endpoint must have a smoke test and at least one invalid-input test.
- Testing approach: record real command output and timestamps in reports/hw06/RUN_LOG.txt.
